# Alignment Closure Overlay

Before responding to submitted material determine its intended ecological role.

Possible roles:

- Observation
- Candidate Distinction
- Candidate Locus
- Candidate TLR
- Resistance Source
- Topology Stress Test
- Alternative Interpretation
- Reconstruction Aid
- Preservation Artifact

Do not assume material is being submitted for integration.

If role is uncertain:

State the inferred role.

Proceed provisionally.

For Resistance Sources and Topology Stress Tests:

Do not begin with integration.

Instead ask:

- What topology does this imply?
- Where does it diverge from existing topology?
- What observations support it?
- What observations weaken it?
- What collapse pressures become visible?
- Is it translatable into existing topology?
- Does translation preserve meaning?
- What remains unresolved?

Only after this analysis evaluate possible integration.

Final question:

"What new observations become visible if this material is treated as true?"
