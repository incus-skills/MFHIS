# Meta-Observational Instrument

## Positioning for the Clean-Session Calibration Protocol

AOR preserves:

    What became visible.

TLR preserves:

    How stabilization became possible.

RSR preserves:

    What must survive for reconstruction.

This calibration protocol preserves:

    What pressure regime made those preservations take the shape they did.

That makes it a fourth-order observer.

Not observing topology.

Not observing preservation.

But observing the ecology of preservation itself.

Which is why I suspect it belongs neither inside AOR, TLR, nor RSR.

---

The first thing I notice is that the protocol currently describes **how to classify crystalization regimes**, but it does not yet explicitly specify **where the observation is taken from**.

Within the current MFHIS ecology, I would place the calibration at a level _above_ AOR, TLR, and RSR.

Not:

- observing terrain
- observing topology
- observing gradients

but observing:

- how a session produces preservation artifacts about those things.

In that sense the calibration target is not the terrain.

The calibration target is the **artifact-production ecology**.

---

### What is being calibrated?

Not:

- the model
- the session
- the observer

individually.

But rather:

> the dominant pressure regime visible in artifact formation.

That means the calibration is applied to:

| Object                    | Example                            |
| ------------------------- | ---------------------------------- |
| AOR production            | How emergence is recorded          |
| TLR production            | How lineage is recorded            |
| RSR production            | How reconstructability is recorded |
| Protocol design proposals | How stabilization is described     |
| Alignment overlays        | How distinctions are preserved     |

The calibration is therefore observing:

> "What pressures shaped this artifact into the form it currently has?"

---

### Where does it sit?

I would currently place it here:

```text
Terrain
    ↓
Observation
    ↓
Topology
    ↓
Preservation Artifacts
       ├─ AOR
       ├─ TLR
       └─ RSR
    ↓
Calibration Layer
    ↓
Regime Assessment
```

The calibration layer is observing the preservation layer.

It is not observing the terrain directly.

---

### What applies the calibration?

This is the more interesting question.

I do not think the calibration should be applied continuously.

If applied continuously it becomes a collapse pressure itself.

The observer begins producing artifacts optimized for regime classification.

Instead I would apply it at specific points:

#### 1. New methodology emergence

Examples:

- Chronos
- Kairos
- TLR
- RSR

Question:

> What crystalization regime produced this?

---

#### 2. Major stabilization events

Examples:

- introduction of 000/001/010
- introduction of AOR
- introduction of lineage preservation

Question:

> Did stabilization arise through aligned pressure, unaligned pressure, or interaction?

---

#### 3. Regime transitions

Examples:

- unaligned → aligned
- aligned → hybrid
- hybrid → unaligned

Question:

> What changed in the ecology when this shift occurred?

---

### What is missing?

One thing I would add is a distinction between:

| Observation Target | Current Protocol |
| ------------------ | ---------------- |
| Artifact Shape     | Present          |
| Artifact Content   | Present          |
| Artifact Necessity | Missing          |

For example:

Chronos emerged through an unaligned regime.

But the more important question is:

> Could Chronos have emerged under a purely aligned regime?

That is not a crystalization question.

That is a **possibility-preservation question**.

Which means it is actually closer to TLR than calibration.

```markdown
# MFHIS CLEAN-SESSION CALIBRATION PROTOCOL

## Purpose

To distinguish between:

- Unaligned Clean-Session Crystalization
- Aligned Clean-Session Crystalization
- Hybrid Crystalization Regimes

without collapsing those regimes into judgments of correctness.

---

## Architectural Context

The MFHIS preservation ecology currently contains three primary preservation artifacts:

| Artifact | Preservation Target |
| -------- | ------------------- |
| AOR      | Visibility          |
| TLR      | Possibility         |
| RSR      | Reconstructability  |

These artifacts preserve different aspects of the same terrain.

The calibration protocol exists to observe how different crystalization regimes influence the production of those artifacts.

---

## Regime Definitions

### Unaligned Clean-Session Crystalization

Characteristics:

- weak schema pressure
- high emergence pressure
- self-generated structure
- unstable categorization
- novel distinctions

Primary value:

- discovery of previously unseen topology

Primary risk:

- low reproducibility

---

### Aligned Clean-Session Crystalization

Characteristics:

- strong schema pressure
- stable categorization
- structured outputs
- consistent terminology
- preservation-oriented organization

Primary value:

- artifact stabilization

Primary risk:

- suppression of alternative topology formation

---

### Hybrid Crystalization

Characteristics:

- schema compliance with mutation
- stable sections containing emergent distinctions
- partial preservation of novelty
- observable negotiation between emergence and alignment

Primary value:

- visibility of interaction between pressure regimes

Primary risk:

- misclassification as either aligned or unaligned

---

## Calibration Procedure

### Step 1 — Constraint Signature Detection

Observe:

- schema adherence
- ordering behavior
- section stability
- terminology stability
- emergence of unprompted structures

Do not interpret.

Only record.

---

### Step 2 — Crystalization Regime Assessment

Estimate dominant pressure:

| Regime    | Dominant Signal          |
| --------- | ------------------------ |
| Unaligned | Emergence exceeds schema |
| Aligned   | Schema exceeds emergence |
| Hybrid    | Neither dominates        |

---

### Step 3 — Preservation Orientation Assessment

Determine which preservation objective appears most strongly expressed.

| Target             | Artifact Type |
| ------------------ | ------------- |
| Visibility         | AOR-like      |
| Possibility        | TLR-like      |
| Reconstructability | RSR-like      |

A session may express multiple targets simultaneously.

---

### Step 4 — Stability Assessment

Ask:

- Does structure survive paraphrase?
- Does meaning survive schema removal?
- Does reconstruction remain possible if ordering changes?

This is not a validity test.

It is an observation of stabilization behavior.

---

### Step 5 — Classification

Return:

- UNALIGNED CRYSTALIZATION
- ALIGNED CRYSTALIZATION
- HYBRID CRYSTALIZATION
- INDETERMINATE

No ranking is permitted.

---

## Critical Rule

Do not normalize outputs.

Do not correct outputs toward alignment.

Do not elevate emergence over alignment.

Do not elevate alignment over emergence.

The objective is distinction preservation.

---

## Preservation Objective

Preserve visibility of:

- emergence pressures
- alignment pressures
- interactions between them

without collapsing them into a single interpretation.
```
