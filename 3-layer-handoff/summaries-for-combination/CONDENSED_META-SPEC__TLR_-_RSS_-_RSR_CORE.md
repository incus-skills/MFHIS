**Function:** Preserve _how stabilization became possible_

- Treats stabilization as an _event with a history_

  > _“How did this become possible?”_

- Lineage without usability

### RSR — Reconstructive Sufficiency Record (Forward-Facing)

**Function:** Preserve _what must remain true for reconstruction_

- Ensures future observers can rebuild topology
- Selects for **sufficiency over completeness**

  > _“What must remain available for this to be reconstructed?”_

**Risk:**

- Omitting unseen dependencies
- Losing lineage while preserving function

---

### RSS — Recursive Specification Stabilization (Meta-Process)

**Function:** Preserve the ecology that produces stabilizable specifications

- Not a record type but a **disciplinary loop**
- Converts artifacts into **pressure injections**
- Operates via:

  ```
  Submit → Analyze → Distinguish → Pressure → Refine → Resubmit
  ```

- Treats:
  - artifacts as projections
  - interpretation as signal of ecological behavior
  - collapse as observable structure, not failure
