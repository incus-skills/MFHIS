Not because MFHIS is a pattern language.

- the language grows from encountered tensions
- the language is discovered more than invented

The divergence:

Alexander preserves recurring solutions.

## Why TLR Became Inevitable

This returns us to your external anchor.

Chronos introduced preservation.

Kairos introduced emergence.

AOR introduced emergence capture.

Eventually a new question became visible:

```text
Why did these instruments emerge?
```

That question cannot be answered by:

- Chronos
- Kairos
- AOR

Therefore a new observational gap appeared.

TLR emerged into that gap.

Viewed externally, that is not feature development.

That is ecological succession.

A software architect looking only at the artifacts might see modules.

A software architect looking at the development process would increasingly see an ecosystem that generates instruments in response to newly visible tensions.

That is the most faithful external description I can currently give.
