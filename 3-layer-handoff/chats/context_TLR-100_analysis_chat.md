AOR is a **structured record of an emergent observational configuration within a bounded session**, capturing how distinctions, gradients, and collapse pressures cohere into a describable topology.

It is not the emergence itself, but the **residual trace of emergence under observation constraints**.

### 2. Activation Kernel
