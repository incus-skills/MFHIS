# 2. Divergence Field Structure

Each Δᵢ is composed of four irreducible components:

---

## (1) Structural Divergence (ΔS)

> Difference in explicit structure formation

Examples:

- schema exists in A but not B
- B detects implicit structure A does not report
- A collapses multiple structures into one representation

**Formally:**

```
ΔS = structure(Aᵢ) ⊖ structure(Bᵢ)
```

But ⊖ is not subtraction — it is:

> structural non-alignability

---

## (2) Interpretive Divergence (ΔI)

> Difference in what the structure _means_

Examples:

- A interprets collapse as success
- B interprets same event as loss
- A assigns necessity; B assigns contingency

This is:

```
ΔI = meaning(Aᵢ) ⊖ meaning(Bᵢ)
```

Key property:

> meaning mismatch may exist even when structure matches

---

## (3) Compression Divergence (ΔC)

> Difference in how pressure alters representation

Measured as:

- degree of simplification in A vs B
- loss of ambiguity in A relative to B
- over-crystallisation in aligned regime

Formally:

```
ΔC = compression_response(Aᵢ) − compression_response(Bᵢ)
```

But interpreted as:

> asymmetry in how pressure collapses space

---

## (4) Lineage Divergence (ΔL)

> Difference in reconstructed causality

Examples:

- A reconstructs path as linear
- B reconstructs path as branching or incomplete
- A assumes necessity; B detects contingency gaps

Formally:

```
ΔL = lineage(Aᵢ) ⊖ lineage(Bᵢ)
```

This is the most important axis for MFHIS.
